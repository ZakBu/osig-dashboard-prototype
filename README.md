# Дашборд рейсов отходов — прототип

Кликабельный прототип: https://zakbu.github.io/osig-dashboard-prototype/

Это отдельная демонстрационная версия интерфейса. Все данные синтетические, корпоративный API не используется. Демонстрационный период — 17–30 октября 2026 года. Показатели рассчитываются по синтетическим рейсам, сравнение — с предшествующим периодом. Поддержаны вкладки, выбор периода, фильтры, графики и реестр рейсов.

Локальный запуск: `npm ci --legacy-peer-deps && npm run dev`.
Статическая сборка: `BASE_PATH=/osig-dashboard-prototype npm run build`.
Публикация: GitHub Pages из каталога `docs` ветки `main`.

## Оперативный свод

У показателей независимые периоды и время (МСК, включительно от 00:00:00 до 23:59:59). По умолчанию — текущий день; для динамики и среднего числа рейсов — семь календарных дней, включая текущий. Данные демо остаются за 17–30 октября 2026 года: вне диапазона показатели пустые или нулевые.

Среднее число рейсов — рейсы / календарные дни; рейсы на ТС — рейсы / уникальные ТС с рейсами. Среднее расстояние — по демонстрационным маршрутам рейсов. Масса — по завершённым рейсам с известной массой. Активность ресурсов исключает отмену и подачу; знаменатель — полный синтетический реестр, включая резерв. Фильтры перевозчиков, ОО и отходов влияют на числитель активности.

Графики ОО по активности, виду строительства и финансированию связаны со списком ОО общим периодом и фильтрами. Географическая карта в текущем прототипе отсутствует.

### Общие компоненты и компоновка

«Свод», «Структура» и «Аналитика» используют общие `AnalyticsKpi`, `TrendCard`, `AnalyticsRankingBars` и `DashboardPrimitives`. Настройка независимого периода вынесена в `PeriodControl` на базе общего Popover. На десктопе «Свод» помещается в один экран: KPI, динамика, активность ресурсов и три графика ОО. Список объектов и связанные фильтры открываются в общем Dialog; на мобильном используется последовательная раскладка.
